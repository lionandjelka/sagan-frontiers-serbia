# Sagan Frontiers | Serbia 2026

GitHub Pages package.

## Files
- `index.html` — page structure/content
- `styles.css` — all styling
- `script.js` — navigation/scroll effects
- `assets/` — place for local images, logos, downloads, etc.

## Publish on GitHub Pages
Upload the contents of this folder to the root of a public GitHub repository. Then open Settings > Pages, choose **Deploy from a branch**, select `main` and `/ (root)`.

## Images currently loaded from authoritative external sources
The current Sagan portrait, Pale Blue Dot image, book covers, AOB logo and IPB logo are loaded by HTTPS from their source sites. This means the website works online without copying those image files into the repository. If you later want a fully offline/self-contained media package, replace those URLs with local files in `assets/` and update the corresponding `src` paths in `index.html`.
